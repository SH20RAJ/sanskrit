# Sanskrit Next (संस्कृत) Language Engineering Skill

## 1. Architectural Model & Core Tenets
1. Dual-Script Invariance: 100% syntactic & semantic parity between Devanagari (U+0900–U+097F) and ASCII.
2. Tiered Execution: Sub-2ms cold boot Tier-0 Bytecode VM (1.84 ms) + optimizing MLIR/LLVM release pipeline.
3. Memory Safety: Zero-GC, deterministic RAII ownership, parameter modes (पठन/read, परिवर्तन/mut, स्वामित्व/owned).
4. Scientific Primitives: Strided tensors (दिश / Tensor), GEMM operator (@), forward-mode autodiff (4.09 ms / 100k evals).
5. Zero-Dependency Native Architecture: 100% native Rust, single 4.2 MB binary.

## 2. Dual-Script Keywords
- Function: कार्य <नाम>(<मापदण्ड>): <प्रकार>  |  fn (): 
- Variable: मान <नाम> = <मूल्य>               |  let  = 
- Constant: स्थिर <नाम> = <मूल्य>             |  const  = 
- If / Else: यदि <शर्त>: ... अन्यथा: ...      |  if : ... else: ...
- Loops: यावत् <शर्त>: ...                   |  while : ...
- Return: प्रत्यागम <मूल्य>                   |  return 
- Output: मुद्रण(...args)                    |  print(...args)
- Panic: विफल(सन्देश)                        |  panic(msg)
- Assert: निश्चय(शर्त, सन्देश)               |  assert(cond, msg)

## 2.1 Phonetic Romanized Typing (DX Superpower)
Type phonetic English on any QWERTY keyboard; autocompletes to Devanagari:
- mudran / mud ➔ मुद्रण(...) [print]
- karya / kary ➔ कार्य [fn]
- maan / man   ➔ मान [let]
- sthir        ➔ स्थिर [const]
- yadi         ➔ यदि [if]
- anyatha      ➔ अन्यथा [else]
- yaavat       ➔ यावत् [while]
- dish         ➔ दिश[...] [Tensor]
- purnank      ➔ पूर्णाङ्क [i32]
- sutra        ➔ सूत्र [str]
- tarka        ➔ तर्क [bool]
- dashamalav   ➔ दशमलव [f64]

## 3. Types
- Primitives: पूर्णाङ्क (i32), दशमलव (f64), तर्क (bool), सूत्र (str), अक्षर (char), शून्यम् (void)
- Tensors: दिश[dtype, shape] / Tensor[dtype, shape]
  - दिश.zeros([M, N]), दिश.ones([M, N]), दिश.randn([M, N]), दिश.eye(N)
  - Tensor @ Tensor (GEMM), .transpose(), .reshape(), .sum(), .mean()
- Automatic Differentiation: Dual(primal, tangent), अवकलन(f, x) [diff], प्रवणता(f, x) [grad]

## 4. Standard Library Modules
- std.core: मुद्रण (print), विफल (panic), निश्चय (assert)
- std.tensor: Linear algebra, strided views, matrix multiplication (@)
- std.autodiff: Forward-mode automatic differentiation
- std.linalg: GEMM, vector norms, matrix operations
- std.math: Trigonometric, logarithmic, and power routines
