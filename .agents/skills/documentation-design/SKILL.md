# Sanskrit Next Documentation Design Skill

## Purpose
Enforces the unique visual and design identity of Sanskrit Next: an ancient scholarly manuscript fused with a modern compiler laboratory and high-end developer tooling.

## When to Use
- Designing web components, layouts, or CSS tokens for documentation sites.
- Styling code blocks, benchmark visualizations, or architecture diagrams.
- Creating playground interfaces.

## Decision Tree
1. Does the visual design use the approved palette?
   - Surfaces: Parchment/Ivory (`#FAF8F5`, `#F5F2EB`).
   - Ink: Deep Stone/Ink (`#1C1917`, `#292524`).
   - Accents: Restrained Saffron (`#D97706`) and Vermilion (`#DC2626`).
2. Does it avoid generic cultural clichés or noisy rainbow gradients?
   - If NO: Redesign with clean geometric rules, Devanagari typography, and generous whitespace.

## Mandatory Checks
- Verify Devanagari font rendering (e.g. Noto Sans Devanagari, Rozha One) aligns with Latin typography (Inter, JetBrains Mono).
- Ensure dark mode maintains contrast and legibility.
